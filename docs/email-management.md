# 邮箱管理操作说明（Refs #146 / Refs #113）

本阶段已开放成员 / 管理员共用的 `/account/email`，未启用全员邮箱门禁。登录、注册、改密默认落点不变；未绑定、邮件关闭 / 故障、豁免到期均不拦原有业务。强制改密始终优先。

## 管理员主动预绑定

1. 用自己的 QQ 登录；若提示初始 / 临时密码，先在既有改密页完成改密。
2. 从账号菜单选择“邮箱管理”。无 MemberProfile 的管理员同样可用。
3. 输入本人实际可用邮箱，发送验证码，检查收件箱 / 垃圾箱，填写 6 位码并确认。
4. 成功后当前 Cookie 换为新 Session，保持原有效期与 rememberMe，其他设备需重新登录；邮箱不公开展示，仅用于找回 / 安全收信准备。找回 HTTP 尚未开放。

## 换绑与旧邮箱不可用

正常换绑须现验当前密码，先收旧邮箱码；填写旧码与新地址，等待跨用途 60 秒冷却后给新邮箱发码，最后提交密码及两份验证码。两份码各自 10 分钟到期，最终提交成功前原邮箱始终有效。

旧邮箱不可用时，另一位管理员先通过原联系方式核验本人：打开管理端成员列表常驻“账号邮箱”，输入 QQ 精确查询（覆盖无档案管理员），填写固定新地址与情况原因，创建 30 分钟协助。成员详情也可进入同一面板。需改密账号先改密再创建协助；禁止自助批准自己。用户登录邮箱页，现验当前密码后发新码，再现验密码和新码完成；不能自行替换待办目标。管理员不代发 / 代收 / 消费验证码，不直接标记 verifiedAt。待办可按记录撤销 / 替换；过期、身份或凭据代次变化失效。

## 邮件未启用或故障

未启用时页面显示不可用；故障仅给受控提示，不公开 SMTP 细节。发码失败或未知也已占发送额度，等待 60 秒后由用户主动重试，不自动补发或退款。确认地址、垃圾箱后仍收不到，联系管理员处理。

管理员仍可查询状态、创建 / 撤销协助、授予 / 撤销临时邮箱豁免，无需 SMTP 可用。豁免原因 2–500 字、默认 24 小时、整数 1–168 小时，重新授予必须重新填写原因，禁止给自己授予或续期。过期实时失效，不自动续期。豁免不等于已验证邮箱，不授予找回资格，不绕过强制改密；本轮只保存管理状态，尚不影响业务访问。绑定成功会使原豁免失效。

普通状态和列表只显示脱敏邮箱；“查看完整邮箱并留痕”是显式敏感读取，记录真实操作人与目标账号。原因只写情况，不填写密码、验证码或完整联系方式。

## 联调边界

自动验证使用 Fake Sender。本机当前配置未启用 SMTP，且尚无用户指定的受控账号与收件地址，实际入口发码 / 收码验证待联调。不要用库内地址或生产账号试发；不新增公开调试接口。DirectMail 运输层结论沿用任务 3，本阶段不重复 DNS / 端口核验。
